# Housewarming Invitation Website A responsive, mobile-friendly digital invitation for a Kyrgyz housewarming celebration. The invitation opens from a cream envelope with a gold house seal, then reveals a traditional shyrdak background, house photos, event details, and background music. ## Project structure ```text uy_toy_invitation/ ├── index.html ├── style.css ├── script.js └── assets/ ├── arches.jpeg ├── house-exterior.jpeg ├── interior.jpeg ├── music.mp3 └── shyrdak.jpeg ``` ## Run locally 1. Download or clone this repository. 2. Keep the `assets` folder in the same directory as `index.html`. 3. Open `index.html` in a modern browser. For the most reliable local preview, run a simple development server from the project folder: ```bash python -m http.server 8000 ``` Then open `http://localhost:8000` in your browser. ## Publish with GitHub Pages 1. Create a GitHub repository and upload all project files, including the `assets` folder. 2. Open the repository **Settings → Pages**. 3. Under **Build and deployment**, choose **Deploy from a branch**. 4. Select the `main` branch and `/ (root)` folder, then save. 5. Wait for GitHub Pages to publish the site. ## Customization - Edit the Kyrgyz invitation text and event details in `index.html`. - Replace the images in `assets/` while keeping the same filenames, or update the image paths in `index.html` and `style.css`. - Replace `assets/music.mp3` with your preferred audio file. Keep the filename or update the `src` attribute in `index.html`. - Adjust colors, layout, and animations in `style.css`. - Adjust envelope and music interactions in `script.js`. ## Music playback note Mobile browsers generally block autoplay with sound. The music therefore starts after the visitor taps the envelope. The music control can pause or resume playback. ## Language The source code, comments, and project documentation are written in English. The invitation content displayed to guests remains in Kyrgyz.
